# Gallery images

The Projects gallery (`projects.html`) shows the real, already-installed off-grid
systems. Drop the four photos here with these exact filenames:

| File            | Photo to use                                                    |
|-----------------|-----------------------------------------------------------------|
| `install-1.jpg` | The lithium (LiFePO₄) battery bank with the BMS + SoC display   |
| `install-2.jpg` | The single wall-mounted hybrid inverter (wiring exposed)        |
| `install-3.jpg` | The larger three-phase inverter (factory install)              |
| `install-4.jpg` | The full power room — inverter above, two battery cabinets      |

If a file is missing, the card falls back to a gradient background, so the page
never breaks. `.jpg`, `.png`, or `.webp` all work — just keep the base filename
(`install-1`, etc.). Recommended: ~1200px wide, landscape for 1–3, and a wide
crop for 4 (it is a full-width banner card).
